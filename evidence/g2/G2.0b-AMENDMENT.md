# G2.0b — Ownership-Risk Discovery Amendment

Base: `f106547f08fcfd4ef19de09b8d5d63ecad2e753b`

This amendment does not modify G2.0 retrospectively. G2.0 remains
recorded as:

```text
CORRIGENDUM_CHAIN      0 -> STOP
MULTI_TARGET_MODIFIER  4
runtime changes        0
```

G2.0b resolves the corpus insufficiency before G2.1 by changing the
discovery traversal, not the phenomenon measured.

## 1. What changes

### Event-centric discovery

G2.0 looked target-outward (`T -> posteriores -> corrigendum`), which
requires the downstream target to register the corrigendum directly.
The G1.2 failure mode is more general:

```text
corrigendum M -> corrects instrument C -> C modifies target T
```

`CORRIGENDUM_CHAIN` is replaced by `CORRIGENDUM_PROPAGATION_RISK`: an
event `(M, C, T)` exists when M is a correction instrument that
officially corrects C, C declares a structural modification effect
(`MODIFICA|DEROGA|SUPRIME|AÑADE|SUSTITUYE`) over T, T is a Banco de
España Circular, `T != C`, and T is not in the semantic seen-set.
M need not list T in its own relaciones — that requirement was the
old bias.

### Corrected-instrument resolution (priority, no guessing)

```text
ELI corrects (url_eli /cir/YYYY/MM/DD/N/corrigendum/ matched against
  the CORRIGE-anterior whose texto names Circular N/YYYY)
-> unique official correction relation
-> else AMBIGUOUS, discarded from selection
```

### Scarcity rule (frozen before identities)

```text
unique eligible < 4          -> STOP
chain eligible == 0          -> STOP
multi eligible == 0          -> STOP
1+3 / 2+2 / 3+1              -> all valid
```

### Allocation

Top-1 per class; remaining slots by best normalized within-group rank
(`rank / eligible_count`), tie `sha256("regdelta-g2b-fill-v1"|boe_id)`.
Dual-eligible targets materialize once with `risk_classes=[...]`.

## 2. What does not change

- `MULTI_TARGET_MODIFIER` class, its ranking seed and its four
  eligible candidates (recomputed mechanically, reproduced exactly).
- `semantic-seen-set.json` — byte-identical (structural metadata
  reads are not semantic opening).
- DEV composition, hard gates, claim ceiling, one-shot rules.
- `evidence/g2/selection.json` — the G2.0 STOP stays as recorded.

## 3. Evidence allowed

Official relation metadata only (`posteriores`, `anteriores`,
`metadatos` rango/departamento/url_eli). Forbidden for selection:
operation parsing, subject parsing, body semantics,
`history.reconstruct`, binding, queries. Fetched discovery bytes live
under `evidence/g2/discovery-v2/` with a hashed manifest.

## 5. Documented example (not hardcoded)

`BOE-A-2016-5724` (corrects Circular 4/2016, additionally registers
CORRIGE over Circular 4/2004) appears in the discovered event set as
`(2016-5724, 2016-4356, 2004-21845)` — found by traversal, never by
literal. The example justifies the design; it is not selection input.

relation graph provided sufficient fresh ownership-risk targets.
